Localise the suffix and add seven language files

The suffix was a hard-coded literal, so every player saw the same Chinese text
regardless of the language they picked in game. It is now a translation key,
meowify.suffix, resolved by the client from assets/meowify/lang/<locale>.json.
Switching language in game therefore updates the suffix without a restart, and
resource packs can override it.

Ships en_us, zh_cn, fr_fr, es_es, pt_br, ru_ru and ja_jp. Any other locale falls
back to en_us. Adding another language needs no code change: drop a
<locale>.json into the lang directory.

All three call sites (the item tooltip, the hotbar overlay mixin and the Jade
plugin) already went through MeowifyText.appendSuffix, so a single change covers
them. The suffix is still styled with the style of the name it follows, so it
keeps the item's rarity colour.
